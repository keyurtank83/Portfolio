# Keyur Tank — Portfolio

Personal portfolio website built from scratch using HTML, CSS and JavaScript.

## Sections
- **About** — Introduction and quick info
- **Skills** — Technical skills with animated progress bars
- **Projects** — 3 real projects (Biometric System, Eric Voice Assistant, Portfolio)
- **Contact** — Contact form with JS validation

## Technologies
- HTML5 (semantic tags)
- CSS3 (custom properties, flexbox, grid, media queries, hover effects)
- Vanilla JavaScript (dark mode, mobile menu, scroll-spy, form validation)

## Features
- Responsive — mobile, tablet, desktop
- Dark / Light mode (localStorage)
- Mobile hamburger menu
- Active nav highlight on scroll
- Form validates before submit
